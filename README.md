# 기타 지판 퀴즈 PWA

별도 프로그램이나 Python 설치 없이 브라우저에서 실행하는 반응형 웹앱입니다.

## 가장 간단한 실행

압축을 푼 뒤 `index.html`을 더블클릭합니다.

- Windows/macOS 브라우저에서 기본 퀴즈 기능을 바로 사용할 수 있습니다.
- 설정값은 브라우저의 로컬 저장소에 저장됩니다.
- 파일 직접 실행 시 브라우저 보안 정책상 PWA 설치와 오프라인 캐시는 활성화되지 않을 수 있습니다.

## PWA로 사용하기

폴더 전체를 GitHub Pages, Cloudflare Pages, Netlify 등 정적 웹 호스팅에 올리면 됩니다.
웹 주소로 접속한 뒤 다음처럼 설치할 수 있습니다.

- Chrome/Edge: 주소창 또는 메뉴의 앱 설치
- iPad Safari: 공유 → 홈 화면에 추가 → 웹 앱으로 열기 활성화
- 삼성 인터넷: 메뉴 → 페이지 추가 → 홈 화면

한 번 접속한 후에는 서비스 워커 캐시를 통해 오프라인 실행이 가능합니다.

## 로컬에서 PWA 기능 테스트

Python이 설치된 개발용 컴퓨터라면 이 폴더에서 다음 명령을 실행할 수 있습니다.

```bash
python -m http.server 8080
```

그 후 `http://localhost:8080`으로 접속합니다. Python이 없어도 실제 사용 환경에서는 정적 호스팅 주소만 있으면 됩니다.

## 주요 기능

- 0~3, 5, 7, 9, 12프렛 범위 선택
- 지판 음 맞히기: C~B의 한 옥타브 건반 선택
- 코드 맞히기: 실제 연주 가능한 코드폼 기반 3지선다
- Major, Minor, 7, m7, maj7, sus2, sus4 출제 범위 설정
- 브라우저 크기에 반응하는 데스크톱·태블릿·모바일 화면
- 점수 표시 및 정답 피드백
- 설정 브라우저 저장
- 키보드: 코드 선택 1/2/3, 다음 문제 Enter, 음 문제 A~G
