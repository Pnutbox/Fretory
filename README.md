# 프렛토리 (Fretory) V4.14

기타 지판의 음과 코드 구성음을 연습하는 반응형 PWA입니다. 별도 설치 프로그램이나 서버가 필요하지 않습니다.

V2.3에서는 첫 화면에서 음 위치, 코드 이름, 실전 코드폼 학습 목적을 한눈에 확인할 수 있도록 디자인을 개선했습니다.

V2.4에서는 코드폼이 위치한 프렛 구간만 자동으로 확대해 스마트폰에서도 운지를 한눈에 볼 수 있습니다.

V2.5에서는 실제 프렛 간격, 개방현·뮤트현, 손가락 번호와 바레 운지를 표시하며 난이도를 실제 운지 난이도에 맞게 재구성했습니다. 음 이름은 올림표와 내림표 중 선택할 수 있고, 점수는 음 연습과 코드 단계별로 따로 집계됩니다.

V2.5.1에서는 프렛 선, 프렛 번호와 문제 마커가 동일한 좌표를 사용하도록 수정해 모든 화면 크기에서 위치가 정확히 일치합니다.

V2.6에서는 오픈·E형 바레·A형 바레 코드폼 선택, 접을 수 있는 정답 해설, 오답 우선 적응형 복습과 학습 통계 화면을 추가했습니다.

V2.8에서는 앱 이름과 첫 화면을 `코드 앤 프렛`으로 개편하고, 세 가지 학습 영역에 바로 접근할 수 있게 했습니다. 설정에는 정답률과 오답 복습 기록만 안전하게 초기화하는 기능을 추가했습니다.

V2.9에서는 설정의 코드 종류를 학습 난이도별로 묶고 전체 선택·해제 기능과 상위 단계의 코드폼 확장 안내를 추가했습니다.

V3.0에서는 add9·6·m6·dim·aug·m7♭5·dim7·9 코드와 실제 기타폼을 추가했습니다. 코드 종류와 별개로 오픈·이동형·바레·높은 포지션을 복수 선택할 수 있습니다.

V4.0에서는 코드 난이도와 CAGED 폼·프렛 범위·바레 조건을 완전히 분리했습니다. 1~3단계에서도 이동 CAGED 폼을 출제하며, 코드 종류·폼·위치·줄·화성학 단원별 통계와 단계형 뒤로가기를 추가했습니다. 화성학 문제 문형도 확장했습니다.

V4.1에서는 CAGED 이동폼의 손가락 번호·부분 바레·뮤트현을 폼별로 보정하고 실전 권장폼과 전체 학습폼을 분리했습니다. 코드의 올림표·내림표 표기를 통일하고, 화성학 4~5단계 상황형 문제 및 설정에서 켜고 끌 수 있는 청음 문제를 추가했습니다.

V4.2에서는 상단 브랜드 영역을 지판 모티프의 좌측 정렬 로고로 개편하고, 문제 마커의 강한 광택을 줄이면서 대비를 유지했습니다. 지판 아래 프렛 숫자도 더 크고 선명하게 조정했습니다.

V4.3에서는 개방현과 뮤트 표시를 같은 중심과 크기의 단일 원·× 기호로 통일하고, 프렛 숫자를 한 단계 더 키웠습니다.

V4.4에서는 표시 생성 코드에서도 기존 문자 기호를 제거하고 개방현·뮤트를 동일한 28px 정렬 상자에 배치했습니다. 프렛 숫자는 더 크게 조정했으며, 새 스타일이 즉시 적용되도록 캐시 버전을 갱신했습니다.

V4.5에서는 개방현 원과 뮤트 ×를 약 30% 확대하고 선 굵기와 색상 대비를 높여 작은 모바일 화면에서도 쉽게 확인할 수 있도록 조정했습니다.

V4.6에서는 개방현 원을 최대 32px, 뮤트 ×를 최대 42px로 크게 확대하고 지판 마커 수준의 굵기와 대비를 적용했습니다.

V4.7에서는 스마트폰 문제 화면의 제목·정답률·여백·지판·건반 높이를 압축하고, 정답 후 다음 문제 버튼을 화면 하단에 바로 표시합니다. 음 맞히기 지판도 출제된 음을 포함하는 3~4프렛 구간으로 자동 이동·확대됩니다.

V4.8에서는 화성학 문제를 한 회차 동안 중복 없이 모두 소진한 뒤 다시 섞도록 변경했습니다. 비슷한 문장은 가능한 한 서로 떨어뜨리고, 적응형 복습은 문제를 반복 삽입하지 않고 오답 문제의 회차 내 순서만 앞당깁니다.

V4.9에서는 새 문제 순환 중 오답 문제를 최대 40문제 이내에 복습으로 다시 출제합니다. 같은 문제를 반복해서 틀리면 간격이 40→33→26→19→12→6문제로 짧아지고, 맞힐 때마다 반대로 길어지다가 일반 문제 상태로 복귀합니다.

V4.10에서는 화성학 1·2단계의 반복적인 문제 생성 틀을 교체했습니다. 각 범위에 10개의 독립 문제 유형을 적용하고 같은 유형이 연속 출제되지 않도록 출제 순서를 분산했습니다.

V4.11에서는 화성학 1·2단계를 각 200문제와 15개 이상의 유형으로 확장하고, 설정 화면 하단에서 현재 설치된 앱 버전을 확인할 수 있도록 했습니다.

V4.12에서는 화성학 1·2단계에 계산형·역추론형·연주 상황형 문제군을 추가하고, 3단계 음계 용어를 영어 표기로 정리했습니다. 시작 화면의 세 연습 버튼은 아이콘과 색상 구분을 강화했습니다.

V4.13에서는 앱 이름을 `프렛토리(Fretory)`로 변경하고, 땅콩 캐릭터·땅콩통·Lakewood M-14 CP에서 영감을 받은 기타가 담긴 새 설치 아이콘을 적용했습니다.

V4.14에서는 첫 화면의 세 학습 아이콘을 더 크게 표시하고, 메인 문구를 `지판을 읽고, 코드를 이해해 내 연주로 만드세요.`로 변경했습니다.

V2.7에서는 기초 화성학과 응용 화성학 범위를 먼저 선택한 뒤 각각 5단계, 단계별 100문제에서 객관식과 O/X가 자동으로 혼합 출제되는 화성학 퀴즈를 추가했습니다.

## GitHub Pages에 교체 업로드

1. 이 ZIP의 압축을 풉니다.
2. GitHub의 `pnutbox/fretboard-trainer` 저장소에서 **Add file → Upload files**를 누릅니다.
3. 압축을 풀어 나온 파일과 `icons` 폴더를 저장소 최상위에 모두 올립니다. 기존 파일은 같은 이름의 V2 파일로 교체됩니다.
4. **Commit changes**를 누릅니다.
5. 보통 1~3분 뒤 기존 주소 `https://pnutbox.github.io/fretboard-trainer/`를 새로고침합니다.

이전 서비스 워커가 남아 예전 화면이 보이면 브라우저 탭을 완전히 닫았다가 다시 열거나, 사이트 데이터를 한 번 삭제한 뒤 접속하세요.

## 포함 기능

- 음 맞히기: HTML/CSS로 만든 한 옥타브 피아노 건반
- 코드 맞히기: Major, Minor, 7, m7, maj7, sus2, sus4
- 코드 맞히기 1~5단계 난이도와 실제 오픈·바레·sus·7th 코드폼
- 각 기타 줄에는 실제 운지처럼 하나의 프렛 또는 하나의 개방현만 표시
- 연습 선택 화면에서 최대 프렛 3, 5, 7, 9, 12 선택
- 에보니 스타일의 어두운 지판과 줄 위에 정확히 표시되는 고대비 마커
- 점수와 설정의 기기 내 자동 저장
- 모바일·태블릿·데스크톱 반응형 화면
- 홈 화면 설치 및 오프라인 실행
- 키보드: 음 선택 A~G, 코드 선택 1~3, 다음 문제 Enter

## 파일 구조

- `index.html`: 앱 기본 화면
- `styles.css`: 디자인과 반응형 레이아웃
- `app.js`: 화면 컴포넌트와 퀴즈 로직
- `theory-questions.js`: 화성학 문제 생성과 범위 데이터
- `manifest.webmanifest`: 설치형 앱 정보
- `sw.js`: 오프라인 캐시
- `icons/`: 앱 아이콘
